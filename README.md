# Maedeh Dehghan’s portfolio

A static website for GitHub Pages. No build tools or dependencies are required.

## Preview locally

From this directory, run:

```sh
python -m http.server 8000
```

Open http://localhost:8000 in your browser.

## Edit

- `index.html`: biography, skills, experience, education, and contact links.
- `css/portfolio.css`: layout, typography, and responsive styles.
- `js/portfolio.js`: mobile navigation and the footer year.
- `media/`: portrait and favicon.
- `uploads/maedeh-dehghan-cv.pdf`: current CV; replace this file to update it.
- `cv.html`: compatibility link to the current CV.
- `404.html`: fallback for missing or retired pages.
- `robots.txt` and `sitemap.xml`: search engine discovery.
- `CNAME`: existing GitHub Pages domain configuration.

Commit and push changes through your usual GitHub Pages workflow to publish.
